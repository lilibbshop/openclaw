# Mac 远程节点 / 长期服务 — 手动运行指令

所有命令均假设在 **openclaw 项目根目录** 执行，或使用绝对路径。

---

## 一、电源与合盖不眠

```bash
# 1. pmset 电源设置（需 sudo，插电时合盖不眠）
cd /Users/ian/openclaw/scripts/mac-remote-node
sudo ./set_pmset_remote_node.sh

# 2. caffeinate 合盖不眠（若未用 LaunchAgent）
cd /Users/ian/openclaw/scripts/mac-remote-node
./start_caffeinate.sh

# 停止 caffeinate
kill $(cat ~/.caffeinate_remote_node.pid) 2>/dev/null
```

---

## 二、一键配置 / 重启

```bash
cd /Users/ian/openclaw/scripts/mac-remote-node

# 一键配置（pmset + caffeinate，pmset 会提示输入密码）
./setup_all.sh

# 安装开机自启（caffeinate + 传家纪 DB 隧道 + 微信发布）
./install-on-login.sh

# 重启所有长期服务
./restart_services.sh
```

---

## 三、传家纪（chuanjiaji）

```bash
cd /Users/ian/chuanjiaji

# chuanjiaji PostgreSQL 隧道（127.0.0.1:5433）
bash scripts/install-db-tunnel-agent.sh

# yinsight PostgreSQL 隧道（127.0.0.1:5434）
bash scripts/install-yinsight-db-tunnel-agent.sh

# 微信体验版自动发布（安装为 LaunchAgent，每 60 秒检查 main）
bash scripts/install-local-wechat-release-agent.sh

# 手动建立 DB 隧道（保持终端不关）
bash scripts/tunnel-server-db.sh          # chuanjiaji -> 5433
bash scripts/tunnel-yinsight-db.sh       # yinsight -> 5434

# 手动执行一次微信发布
bash scripts/watch-main-and-release-wechat.sh
```

---

## 四、查看状态

```bash
# 所有长期服务状态
launchctl list | grep -E 'openclaw|chuanjiaji'

# PostgreSQL 隧道是否连通
nc -z 127.0.0.1 5433 && echo "chuanjiaji 已连接" || echo "chuanjiaji 未连接"
nc -z 127.0.0.1 5434 && echo "yinsight 已连接" || echo "yinsight 未连接"

# 日志
tail -f ~/Library/Logs/chuanjiaji-db-tunnel.log
tail -f ~/Library/Logs/yinsight-db-tunnel.log
tail -f ~/Library/Logs/chuanjiaji-wechat-release.log
```

---

## 五、恢复默认（不再作远程节点时）

```bash
# 恢复 pmset 默认
sudo pmset -a sleep 10
sudo pmset -a displaysleep 10
sudo pmset -a disksleep 10

# 停止 caffeinate
kill $(cat ~/.caffeinate_remote_node.pid) 2>/dev/null

# 卸载自启
launchctl unload ~/Library/LaunchAgents/com.openclaw.caffeinate.plist
launchctl unload ~/Library/LaunchAgents/com.chuanjiaji.db-tunnel.plist
launchctl unload ~/Library/LaunchAgents/com.chuanjiaji.yinsight-db-tunnel.plist
launchctl unload ~/Library/LaunchAgents/com.chuanjiaji.wechat-experience-release.plist
```

---

## 六、pmset 命令修正

你当前在 `mac-remote-node` 目录下时，应执行：

```bash
sudo ./set_pmset_remote_node.sh
```

而不是 `./scripts/mac-remote-node/set_pmset_remote_node.sh`（那是从 openclaw 根目录看的路径）。
